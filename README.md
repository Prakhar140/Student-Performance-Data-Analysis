# Student Performance Data Analysis System

## Overview
This project is developed using Python and Pandas to perform data loading, cleaning, transformation, analysis, filtering, sorting, grouping, and report generation on student performance data.

## Technologies Used
- Python
- Pandas

## Features
- Load CSV data
- Clean missing and invalid values
- Transform data by adding Grade, Result, and Performance Score
- Filter student datasets
- Perform statistical analysis
- Generate reports

## Project Structure

data/
output/
src/
main.py

## How to Run

```bash
python main.py
```

## Output 

Running the project generates:

- cleaned_data.csv
- toppers.csv
- failed_students.csv
- low_attendance.csv
- high_study_hours.csv
- report.csv
- grade_distribution.png
